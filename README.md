# インカム (P2P音声通話アプリ)

メンバーがそれぞれのスマートフォンのブラウザから同じルーム名で参加すると、WebRTCでP2P音声通話がつながるシンプルなインカムアプリです。

## 使い方

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開き、ルーム名を入力して「参加」を押します。同じルーム名で他のメンバーも参加すると自動で通話が始まります。

## スマートフォンで使う場合の注意

`getUserMedia`(マイクアクセス)はセキュアコンテキスト(HTTPS、または `localhost`)でのみ動作します。スマートフォン実機で動作確認する場合は、HTTPS化したサーバーにデプロイするか、ngrok などでHTTPSトンネルを経由してアクセスしてください。

## 構成

- `server.js` : Express + Socket.io によるシグナリングサーバー
- `public/` : フロントエンド(ルーム参加・ミュート操作・WebRTCメッシュ接続のロジック)

複数人での通話はメッシュ型(各メンバー同士が直接P2P接続)です。少人数(目安5〜6人程度まで)向けの構成です。
